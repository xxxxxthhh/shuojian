## 怎么重新生成

```
bash dev/qa.sh "tag=new"              # 全部：八关三机位 + 菜单 + 诊断
bash dev/qa.sh "tag=new&only=c4"      # 只跑一关，迭代用
```

`dev/qa.sh` 起 `dev/qa_server.py`（静态服务 + POST 落盘），
用 headless Chrome 打开 `dev/shot.html`，页面里逐屏渲染、统计像素、`toDataURL` 后
POST 回来落盘，最后写 `_stats.json`。纯 dev 工具，游戏本身不依赖任何一个。

## 「纸色留白」是怎么数的

画面按 **4×4 取平均**后，亮度 `L = 0.299R+0.587G+0.114B ≥ 218` 的块算作纸色留白。

- 纸底 `#efe7d8` 的 L = 231.6；四角做旧晕染压到 ≈224（仍算留白）
- 任何 alpha ≥ 0.10 的墨罩 L ≤ 211（不算留白）
- 先做 4×4 平均是为了抹掉纸纹噪点的 ±7 —— 否则任何硬阈值都会在噪点上抖

所以这是个**偏严**的口径：人眼觉得「还是白纸」的极淡洗色，这里已经不算留白了。
DESIGN §1 要求 ≥ 50%。
